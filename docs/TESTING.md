# Validation map

- `lean proof/ShapeCore.lean`: conditional core theorems, executable checker,
  finite audit executor and axiom reports.
- `python -m unittest discover -s tests -v`: source custody, padding, runtime,
  model units, failures, observers and model contracts. Two tests need actual GGUFs.
- `experiments/differential.py`: generated compiler/validator/runtime comparisons.
- `experiments/correspondence.py`: production Runtime, independent JSON interpreter
  and Lean exec on the same finite kernels and programs.
- `python -m orchlang check`: independent source-bound artifact acceptance receipt.
- `legacy/v1/scripts/offline_check.py`: retained C++/Python scientific implementation
  and four Lean files. Optional exact-tokenizer and framework environments are
  documented separately under `legacy/v1/docs`.
- `publication/build_evidence.py --require-complete`: raw paired denominators,
  store equality, full-shape equality, truncations and campaign completion.

See the publication claim ledger for what each check does and does not establish.
Finite testing is not a verified parser, tokenizer or physical backend.
