productive cycles, independent source-cost and graph replay, exact finite
usage channels, finite stochastic equality and exact ordered trace-law equivalence for every finite horizon,
restricted OrchLang/Python source bridges, actual LangGraph execution and
a functioning local HTML demonstration. Its novelty claim is a focused
research-software specialization and inspectable evidence pipeline. Resource
noninterference, quantitative information flow probabilistic bisimulation and weighted-automaton equivalence
are established methods and are attributed.

bounded secret comparisons; 888 actual backend executions; 130 finite channel

certificates/six inconclusive cases, all independently replayed; plus six exact trace-law equality certificates and six finite inequality witnesses across twelve authored models. The latter closes a bisimulation precision gap in one controlled example. The software
makes no real-provider probability, invoice-privacy, arbitrary translation,
termination or mechanized-metatheory claim.
