# Manuscript source and evidence

`main.tex` follows the official SCP Original Software Publication LaTeX template,
with mandatory metadata descriptions and main sections retained. Metadata column
widths fit the class margins; body font/spacing/margins were not compressed.
The PDF is an author-review draft, not an approved/submitted paper. Its public
archival link, competing interests and author approval remain unresolved.

Compile twice with a normal LaTeX distribution containing `elsarticle`, `amsmath`,
`amssymb` and `hyperref`:

```text
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

`evidence/metrics.tex` and `external.tex` are exact copies of files generated by
`scripts/report_publication.py`; their machine-readable source is
`research/validated-2026-10-23/tables/summary.json`. Regenerate to a NEW directory
and compare bytes before replacing manuscript evidence. Keep all files in this
project when making the LaTeX source archive. Highlights are editable text;
each of the four lines is at most 85 characters. The project compiles offline
with the system MiKTeX. The Codex preview compiler was unavailable on this
Windows host because it could not enforce split writable roots.
