# OrchLang: focused software-publication plan

**Target: Science of Computer Programming (SCP), Software Track / Original
Software Publication (OSP).** The contribution is an offline workflow
analysis tool with inspectable evidence, source adapters and reproducible
execution. [Independent final review](FINAL_PUBLICATION_REVIEW.md).

## Current requirements

The [current publisher guide](https://www.sciencedirect.com/journal/science-of-computer-programming/publish/guide-for-authors)
was read on 9 October 2026. It requires the official OSP template without
format-setting changes, a single-column manuscript, completed software
metadata and public external code. It suggests 3–6 pages for abstract and
running text, excluding title/authors/affiliations, references, metadata,
tables and figures. It requires abstract ≤250 words, 1–7 keywords, and a
separate editable file of 3–5 highlights of ≤85 characters each.
[SCP_AUTHOR_REQUIREMENTS.md](SCP_AUTHOR_REQUIREMENTS.md) records all checked
requirements, sources, software/source upload rules, review and policy details.

## Narrative and journal fit

Open with equal budgets but unequal usage. Admit the matched dependent chain
using exact contract/request identity and prior-result correspondence. Explain
productive cycles and independent graph replay. Distinguish expected usage
from exact laws, and aggregate totals from ordered observations. Present
finite stochastic closure as a supplied-model use of established bisimulation,
then explain the exact row-span trace-law decision and its independently replayed proof/witness before showing source provenance and actual LangGraph execution.

The [publisher scope](https://shop.elsevier.com/journals/science-of-computer-programming/0167-6423)
and [OSP editor call](https://eapls.org/news/issues/open-call-for-software-submissions-science-of-computer-programming-software-track-xjw27/)
fit programming-language implementation, analysis and reusable research tools.
The call's six review dimensions guide the internal assessment. The publisher
sets no numeric novelty or acceptance threshold. Current independent review:
originality/significance 6.2/10, candidate-quality proxy 7.4/10, fit 8.5/10;
these are not acceptance probabilities. The requested novelty 8 is unmet.

## Author completion before submission

Confirm author name order, affiliation/postal address, correspondence,
co-authors/contributions, funding and competing interests. Review the code,
claims, references, AI disclosure and final manuscript; supply human
responsibility and approval. Use the actual immutable public software version
and final PDF/source ZIP/highlights. Complete the publisher declaration tool
and select **Original Software Publication** in the journal submission entry.
No submission, editor contact, agreement or publication payment has occurred.

The [journal shortlist](JOURNAL_SHORTLIST.md) retains alternatives. SCP OSP is
the focused route. A technical report can be released without suggesting peer
review; a review article requires systematic review work beyond this audit.
