# Manuscript for *Science of Computer Programming*

"Compare the requests, not their sizes: Resource side channels and sound token
bounds for LLM workflows", prepared for the research-paper track of *Science of
Computer Programming* (Elsevier). `main.pdf` is the current build.

## Build

```sh
make            # figures (TikZ, pgfplots) to fig-*.pdf, then main.pdf
make check      # abstract <= 250 words, 3-5 highlights <= 85 chars, no undefined
                # references, no overfull lines, style word list
make examples   # re-run orchc on the running example; regenerates the quoted diagnostic
make data       # regenerate figure data from bench/results (after bench/evaluate.py)
make bundle     # upload/: flat sources for Editorial Manager, compiled once to prove it builds
```

Needs TeX Live (with `elsarticle`, `pgfplots`, `mathpartir`, `listings`), Python 3
and, for `highlights.docx`, Node with the repository's `docx` dependency
(`npm install` at the repository root).

## Where the content comes from

| Part | Source |
|---|---|
| Every number in the evaluation | `bench/results/evaluation.txt`, from `python bench/evaluate.py` |
| Plots (Figs. 5, 8, 9) | `figures/data.py` reads `bench/results/*.json`; pgfplots draws the CSVs |
| Appendix table of ports | `sections/corpus-table.tex`, generated by `figures/data.py` |
| Running example (Fig. 1) | `examples/triage.orch`, included verbatim; diagnostic from `examples/run.py` |
| Mechanised statements (Fig. 6, Table 4) | `proofs/OrchLang.v` |
| References | `references.bib`: every entry checked against Crossref, arXiv or the publisher |

The house style (numbered references, "Section N" and "Fig. N", a running example,
related work late, rules and syntax as figures, a theorem-to-Coq table, end-matter
order) follows a study of nine recent SCP research papers close to this one, and the
prose was edited against an evidence-based checklist for precise academic writing.

## Before submitting: what only the author can do

- [ ] Put your e-mail address in `main.tex` (`\ead{...}`) and complete the affiliation
      (school or department, postcode).
- [ ] Confirm the CRediT roles and the funding sentence in `sections/endmatter.tex`.
- [ ] Choose a licence for the repository, archive a tagged release on Zenodo, and add
      its DOI to the data-availability statement.
- [ ] Elsevier's June 2026 image policy asks that captions of explanatory diagrams made
      with AI help name the tool, its version and how it was used. Figs. 4 and 7 name
      the tool; add the version, or redraw the diagrams yourself and remove the note.
- [ ] Read the SCP Guide for Authors in a browser; it could not be fetched from here, so
      its rules were taken from search extracts (see `docs/SUBMISSION_PLAN.md`).
- [ ] Add the date, your e-mail and, if you wish, suggested reviewers to `cover-letter.tex`.
- [ ] Complete the declarations tool in Editorial Manager.

## Upload to Editorial Manager

Run `make bundle` and upload, from `upload/`:

- `manuscript.pdf` as the manuscript;
- the LaTeX source files, flat (`main.tex`, `main.bbl`, `references.bib`,
  `elsarticle.cls`, `elsarticle-num.bst`, `fig-*.pdf`, `triage.orch`);
- `highlights.docx` as the highlights;
- `cover-letter.pdf` as the cover letter.
