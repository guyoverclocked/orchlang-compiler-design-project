\section{Observation and semantic boundaries}
\subsection{Abstract requests and accounting}
The core language resolves a model alias to a contract $c$ containing provider/model identity, output cap and any declared price metadata. Lexical identities distinguish shadowed variables. A normalized call has exact decoded template bytes and ordered arguments: literals, fixed public values or positional references to prior matched call results. The abstract request is $Q=(t,\vec v)$. A request-sensitive deterministic oracle is
\[
\Omega(c,k,Q)=(r,u),
\]
where $k$ is the contract invocation ordinal, $r$ a response and $u$ modeled output usage. Two executions with identical keys obtain the same pair. This is a coupling premise about the abstract oracle; SDK framing, tool schemas, hidden context, retry rules and provider wire serialization are absent from $Q$.

For density parameter $d\geq1$, the additive input estimate is
\[
\widehat I(t,\vec v)=\left\lceil|\operatorname{UTF8}(t)|/d\right\rceil+
\sum_i\left\lceil|\operatorname{UTF8}(v_i)|/d\right\rceil.
\]
Static bounds substitute declared argument bounds. Applying such a bound to an external tokenizer requires the per-call premise that every charged request component is covered and actual charged input is at most the derived expression. Equality of provider/model strings does not prove a tokenizer version or that premise. Model results reused across tokenizer identities are rejected by the compiler's compatibility check; no general cross-tokenizer conversion is inferred.

The invocation observer retains ordered $(c,Q,I,O)$ records. An ordered usage observer drops $Q$ and retains $(c,I,O)$; aggregate accounting further groups these labels by contract. Each projection can lose information. For example, swapping $(1,3)$ and $(3,1)$ produces equal totals but different ordered observations. Likewise, equal individual marginals do not identify a joint law: uniform laws on $\{00,11\}$ and $\{01,10\}$ have equal marginals and trace TV one. The artifact contains corresponding negative controls. The selected observer is part of every guarantee.

\subsection{Closed finite-kernel trace equality}
The existing graph analyzer constructs all reachable semantic states under a supplied finite rational success-outcome kernel and listed public/secret stores. A state retains program position, initialized values, result registers, per-contract ordinal saturated at 33, and the configured retained complete-event history. This finite closure is a semantic abstraction, not proof that a provider forgets its history or has saturated ordinal behavior.

For usage symbol $y$, let $A_y$ be its rational transition matrix. For two initial states, $\mu=e_0-e_1$; $t_s,t_l$ are stopped and live indicator columns. For word $w=y_1\cdots y_m$, differences are $\mu A_wt_s$ and $\mu A_wt_l$. Exact row-span exploration closes the space generated by $\mu A_w$. If all spanning rows annihilate both columns, every finite word has equal stopped/live mass. Otherwise the generating word supplies a finite witness. This is established weighted-automaton methodology~\cite{tzeng,kiefer,weighted}. It proves all-finite-horizon success-only equality in the supplied finite model; it does not establish infinite-run behavior or provider probabilities.

The exact replayer reconstructs the closed system, recomputes generator-word rows, checks independence, initial span, transition closure and both outputs. Unequal reports are checked by direct witness probabilities. Bisimulation is a separate sufficient analysis. The fixture \cp{trace_equal_not_bisimilar} has equal usage laws but an inconclusive bisimulation result. The exact tool defaults to 10,000 states, 64 MiB deterministic byte-work, 10,000,000 matrix entries and 8,192 rational bits. Its meter is not RSS. Exhaustion yields UNKNOWN with no partial equality result. Source digests are custody fields, not proof that the recorded executable actually ran.

\section{Normalized returned-state and graph refinement}
\subsection{Snapshot versus eager semantics}
Source nodes read state fields from a fixed node-entry snapshot $S$, compute ordered local call results and return a field/local map $W$. The source atomically commits returned fields after the node completes. Target nodes use an eager store $T$, writing a produced returned local to its field as soon as the call completes. A later state-field read could therefore observe a different value in $T$ than in $S$.

The theorem \cp{node_commit_refines_from} in \cp{proofs/scp_strengthening/SequentialUpdates.v} assumes:
\begin{enumerate}
\item $S$ and $T$ initially agree at every text-field lookup;
\item \texttt{safe\_after [] C W}: after a returned field is eagerly written, later calls do not read that field through a state-field atom;
\item call-result locals, returned fields and returned locals are unique;
\item every returned local is produced by the ordered call list.
\end{enumerate}
Under these premises the resolved abstract request/response histories and local environments agree. The source's final atomic commit agrees field by field with the final eager store. The proof proceeds over calls, maintaining agreement for every field still read from the entry snapshot and agreement of prior local results. The shared oracle is an abstract total function of the modeled request history/request; usage and provider behavior are not part of this theorem.

Three machine-checked counterexamples explain the restrictions. A later read of a just-returned field changes the target request. Returning the same local to two fields leaves an eager register unwritten under the modeled lowering. Returning a field twice can disagree with eager write order. These are theorem-premise witnesses, not bugs claimed to be accepted by the current frontend.

\subsection{Routed finite prefixes}
\cp{finite_prefix_graph_refines_including_cycles} uses separate lists of paired normalized workflow nodes. Calls, return maps and decisions in each pair agree; route targets use the same indices. Decisions are STOP, direct jump, immutable Boolean input or a text-field token comparison using any of $<,\leq,>,\geq,=,\neq$. After a node commits, equal states yield equal route decisions under the shared estimator. Induction on node-transition fuel therefore preserves abstract history, state lookup, status and program counter. Cycles, including a self-cycle, are permitted for every finite node prefix. No termination theorem follows, and node fuel does not model stopping in the middle of a call sequence.

\section{Conservative full-history row-ball bound}
Let $\Sigma$ be a declared complete finite observation alphabet containing a visible STOP symbol. At each scenario and complete visible prefix $h$ before the finite horizon $H$, the caller supplies nominal conditional row $q_i(h)$ and radius $\rho_i(h)$. The premise is
\[
\TV(p_i(h),q_i(h))\leq\rho_i(h)
\]
for the actual conditional row at every reachable history. Marginal constraints alone are insufficient. Missing live rows receive the maximally uncertain distance one. The caller must encode every selected status, usage or metadata field in the finite symbols, or define an explicit projection.

By triangle inequality the local paired distance is at most
\[
d(h)=\min\{1,\TV(q_0(h),q_1(h))+\rho_0(h)+\rho_1(h)\}.
\]
Set $s(h)=1$ at the horizon and after STOP. Otherwise, for the conservative possible common support $K(h)$,
\[
s(h)=(1-d(h))\min_{y\in K(h)}s(hy).
\]
When local distance is one the guarantee is zero; support/empty cases are handled conservatively. Maximal coupling matches the next symbol with probability at least $1-d(h)$. Conditional on a match, the worst child continuation remains at least the displayed minimum. Induction yields a complete trace coupling agreeing with probability at least $s(\epsilon)$; the coupling inequality gives $\TV(P_0,P_1)\leq1-s(\epsilon)$~\cite{coupling}. This uses standard coupling ingredients. The history-dependent fixture has bound $91/100$, versus $99/100$ from a coarser per-depth envelope.

Universal STOP-by-$H$ is a separate traversal over all possible events. If requested and verified, the bounded trace includes completed padded observations. Otherwise the certificate expressly covers the first $H$ slots and reports no termination proof. Errors are symbols, not implicit STOP. STOP padding begins at its first occurrence.

The prototype uses exact rationals and explicit caps: $H\leq10{,}000$, 128 symbols of at most 256 UTF-8 bytes each, 50,000 explicit rows and at most 50,000 caller-selected traversal nodes, 16,000,000 document bytes, 1,000,000 JSON items with depth 64, 128-digit rational parts and 8,192-bit arithmetic. JSON integer inputs have separate digit and 512-bit guards. These maxima are acceptance limits, not demonstrated practical capacities; explicit prefix trees can grow rapidly. Replay traverses the certificate separately but shares parsing, arithmetic and the local obligation helper with the producer. A deliberate local-helper fault injection made both report a false zero distance for distinct deterministic symbols. This demonstrates common-code risk; no such defect was found in the current helper. The producer's output is checked against reader byte/tree caps before emission, and atomic output replacement occurs only after successful construction. The final suite has 23 tests. An independently constructed quarter-grid law enumeration checked 42,875, 117,649 and 15,435 kernel pairs; their maximal TVs were $1$, $3/4$ and $7/8$, against bounds $1$, $3/4$ and $1$. These 175,959 finite probes are falsification evidence, not proof over all real-valued rows.

\section{Exact finite rectangular row-polytope distance}
\subsection{Contract and trace space}
For scenario $i\in\{0,1\}$ and full visible history $h$, the row set is
\[
U_i(h)=\operatorname{conv}\{g_{i,h,1},\ldots,g_{i,h,m}\},
\]
where each $g$ is a rational distribution on the shared finite alphabet. A missing live row is the full simplex, represented by point masses. The contract is rectangular: each row in each scenario may be chosen independently of all other rows. No shared latent parameter, shared randomness or cross-scenario tie is represented. Finite alphabet completeness and conditional-history sufficiency are external premises.

Traces have exactly $H$ slots, padding with STOP after the first STOP. Without the optional universal stopping flag this is only a prefix law. If the flag is true, every positive-support path in both row sets must emit STOP by slot $H$. Errors, finish status and selected usage/metadata are visible ordinary symbols and do not implicitly terminate. The prototype does not infer any such field from an API.

For prefix $h$ and incoming masses $a,b\geq0$, define
\[
C_h(a,b)=\inf_{Q_0,Q_1}\sum_z\min\{a Q_0(z),b Q_1(z)\},
\]
over allowed normalized suffix laws from that prefix. At $|h|=H$, $C_h(a,b)=\min(a,b)$. At a live prefix,
\begin{equation}\label{eq:recurrence}
C_h(a,b)=\min_{g_0\in G_0(h),\,g_1\in G_1(h)}
\left[\sum_{y\neq\STOP} C_{hy}(a g_0(y),b g_1(y))
+\min\{a g_0(\STOP),b g_1(\STOP)\}\right].
\end{equation}
Here $G_i$ is the finite supplied generator list. Branches of zero mass contribute zero. The worst-case complete bounded TV is $1-C_\epsilon(1,1)$.

\begin{lemma}
For any allowed suffix-law set independent of $a,b$, the function $C_h$ is concave and positively homogeneous in its two incoming masses.
\end{lemma}
\begin{proof}
For fixed normalized laws, overlap is
\[
\sum_z\min\{aQ_0(z),bQ_1(z)\}
=\tfrac12(a+b-\|aQ_0-bQ_1\|_1).
\]
Taking its infimum over all suffix pairs yields $\tfrac12(a+b-D(a,b))$, with $D$ the supremum of convex weighted $L_1$ norms. The supremum is convex, so $C_h$ is concave. Scaling both masses scales each norm and overlap, hence positive homogeneity. The finite compact row contract attains its extrema; the same conclusion also follows by finite backward induction.
\end{proof}

\begin{proposition}
Under the stated finite rectangular contract, recurrence~\eqref{eq:recurrence} computes the exact minimum weighted overlap, and $1-C_\epsilon(1,1)$ is the maximum bounded trace TV.
\end{proposition}
\begin{proof}
Partition traces by their next visible symbol. Overlap is the sum of child overlaps with masses $ap_0(y),bp_1(y)$. Rectangularity permits each child subtree's row choices to attain its minimum independently. STOP contributes its immediate overlap because subsequent padding is fixed. By the lemma each child value is concave, so their sum after linear mass scaling is concave in $(p_0,p_1)$. Every point in the product of the two row hulls is a convex combination of generator pairs. Concavity bounds its objective below by at least the minimum objective at a generator pair; since generator pairs are allowed, that minimum is exact. Induct from the horizon. Finally, normalized finite-law TV equals one minus overlap.
\end{proof}

This is a derivation for this finite software contract using established imprecise-probability, robust dynamic-programming and trace-distance ideas~\cite{cooman,tzortzis,chen,bian}. No new general theorem, priority or unbounded exact-distance method is claimed. It also does not establish that an external process satisfies the contract.

\subsection{Separating and scope counterexamples}
The main article's singleton-row (fixed-kernel) half-mass fixture produces $AC$ and $BC$ in scenario 0, and $AD$ and $BC$ in scenario 1, each with probability $1/2$. Its exact overlap is $1/2$, TV $1/2$, while the conservative worst-child continuation loses the matching $B$ mass and returns distance one. The recurrence carries both masses throughout arbitrary subproblems; their ratios can differ under uncertain rows. The fixture demonstrates a useful strict improvement, not empirical privacy protection.

Suppose a single shared parameter forces both scenarios to choose either $\delta_A$ or $\delta_B$. Each paired law has TV zero. Replacing the tied parameter by independently chosen row projections $\{\delta_A,\delta_B\}$ gives rectangular worst TV one. That value is exact for the product superset, not the original tied family. Similarly, dropping error/status fields, using unconditional marginals or omitting out-of-alphabet events changes the subject of the theorem. A row-set inclusion argument and an observer mapping are necessary to transfer its result.

\subsection{Replay, caps and adversarial repairs}
Work can grow exponentially with horizon, alphabet and generator choices; memoization and caps limit successful instances, without a polynomial complexity claim. The producer memoizes $(h,a,b)$, records its minimum and an attaining generator pair, and reserves a state before descent. Replay derives the complete closure under \emph{all} generator pairs, recomputes local minima bottom-up and checks root/backpointer values. It never accepts a certificate solely because the recorded winning pair attains the claimed value. Parser, row lookup and rational arithmetic remain shared trusted code; the checker is not mechanized.

\subsection{Provider calibration plan and publication status}
The offline calibration harness freezes four public synthetic prompts under two mapped OpenAI Responses envelope profiles: eight response cases plus eight input-token preflights, at most 16 wire requests, 1,024 input and 64 output units per case, no tools, no retries/redirects and storage disabled. Provider/model and budget authorization are pending. A proposed \$0.25 planning ceiling is not an authorized spend or guaranteed invoice cap. The runner is tested against fake transports and rejects missing usage fields rather than treating them as zero; cached/reasoning usage are retained when present. Tokenizer cache misses cannot trigger network fetches during offline validation.

These envelopes map selected source-shaped requests; they do not reproduce the original Gemini/AWS/provider SDK paths. A future eight-case sample would be descriptive calibration only, not a conditional-probability estimate, a statistically justified TV radius, future provider coverage or invoice validation. Such claims require a separate sampling/coverage design and the actual provider boundary.
