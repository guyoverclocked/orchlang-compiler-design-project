## What the empirical gains mean

Historical median overhead remains 1.83 times input-plus-four-output logical
usage; its range is 1.13--14.47. New overhead is 1.74/2.34 for Llama corrective/
adaptive RAG and 5.49/2.23/1.82 for Qwen switch/email/corrective RAG. No new cohort
saves against the all-branches dummy baseline. These are logical resource
ratios, not prices or provider invoices.

All saved outputs agree, including weak outputs. New task scores are 28.7% and
51.7% for Llama corrective/adaptive RAG, 60.5% for Qwen switch and 37.3% for Qwen
corrective RAG. The historical calculator remains 1% accurate. The single-class
Qwen corrective-RAG decision cohort provides no meaningful attack result. Timing
is not protected: the historical latency-augmented attack reaches 100% balanced
accuracy. There is no general utility, deployment-security or efficiency claim.

## Novelty and journal assessment

The defensible novelty is a specialized, executable assurance method connecting
bounded usage repair to source-derived acceptance, explicit model/execution
contracts and independently checked evidence. Constant-resource typing,
balancing, supersequences, translation validation, information flow and resource
admission all have close prior art. The budget lemma is a useful fixed-shape
corollary, not a new logic. The matrix in `NOVELTY_AND_JOURNAL_ASSESSMENT.md`
credits those precedents and compares both parents and the combined artifact.

SCP is a plausible scope match for practical formal techniques and experimental
software technology. Full research-article originality remains a serious reviewer
question; an Original Software Publication may be another framing if independent
use and the track's instructions support it. Passing tests supplies neither an
acceptance probability nor a priority guarantee.

## Remaining verification and publication work

The planned local campaign and configured release checks are complete. Important
scientific limits remain, rather than silently becoming completed proof obligations:

1. The Python source reader and concrete backend are trusted. A mechanized
   partial-execution refinement including failures would be new research.
2. Large inference runs identify `6a24fe8`. The later frontend is covered by
   targeted release tests; all four Qwen core candidates are exactly identical
   across versions, but unchanged full-corpus Llama accuracy is not established
   after the frontend correction. A full release-version application rerun would
   strengthen external validity. Historical records are not relabelled.
3. Independent proof/code review and reproduction on another machine/site remain
   unperformed. The independent interpreter is an independent implementation,
   not an independent human investigator.
4. The usage interface must faithfully expose the declared logical counts. No
   authoritative provider-billing/gateway adapter, timing protection, concurrency
   theorem or stateful external-tool guarantee is established.
5. Human authors must review this exact version, approve authorship and wording,
   supply real contributions/funding/conflicts/permissions, check the current
   journal guide, approve a public archive and authorize actual submission.

The package includes review drafts and blank author declarations. No public push,
upload, editor contact, paid API use, journal submission or publishing agreement
has been carried out.
