# Response to the independent third-round review

The review recommended Major Revision (6.0/10) with six major objections. Each
is addressed below by new proofs, code, experiments or text. Lean proofs are
checked by `publication/check_proofs.py`; experiment numbers are regenerated by
`publication/analyze_round3.py` from raw records.

## M1. The security contribution reduces to report normalization

**Reframed (Introduction, "What the guarantee buys"; Section 2).** A report
normaliser still needs a static shape, a preservation check and an admission
check: without admission a normalised report misstates usage when a request
outgrows its slot, or the run must refuse midway and the refusal leaks. Executed
shaping makes the report truthful: it equals the logical work in each model
contract's unit and reconciles with local eval/yield records. The observer is now
the exported per-run usage record, released without per-event timestamps, with
observability tracing conventions and masking features cited as the concrete
setting. The latency attack is retained as the reason for the timestamp
requirement.

The paper now states Theorems 1-5 in restricted/certified form; the global

## M3. Certified chain exercised on only 24 pairs; cost unreported

**Run in full.** The byte-bounded campaign covers every planned input of all
twelve variants at clean commit `e90c7bc` (Table 5). Reported per variant:
executed/planned pairs, guard refusals, saved-field and shape equality,
segmentation receipts per request, clipped pairs, agreement of bounded
originals with the unbounded heuristic originals (same IDs and seeds), maximum
`T+N`, certified cost relative to the original and to heuristic shaping.

**Outcome.**
- Of 1,684 planned inputs, the guard refuses 2 (Calculator) before dispatch.
- All 1,682 admitted pairs complete, with equal saved fields and the certified
  shape. All 10,675 model requests pass the segmentation check.
- The independent audit (`evidence/round3-checks/certified-audit.json`) re-tokenizes
  and reconciles every call against local eval/yield records. It also detects the
  corrupted-count control.

Two results are reported as limitations rather than hidden:
- **Tool clipping changes the application.** Tool buffers (four bytes per declared
  token) clip 1,920 tool results in 471 pairs. Only 1,429 of 1,682 bounded
  originals equal the unbounded heuristic originals; adaptive RAG has 0/60 and
  orchestrator 24/100.
- **Worst-case envelopes are expensive in chains.** The certified median cost is
  6.47× original (2.70× heuristic shaping). Flat workflows cost 2–4×, but chaining
  costs 104× and calculator 47×, because 128-byte-per-token response bounds
  compound through later prompts under alpha = 1.

**Custody note.** Manuscript and documentation files were edited while the campaign
ran, so 11 of 12 manifests carry `git_dirty: true`. All 13 hashed implementation
files are byte-identical to the commit's blobs in every manifest
(`evidence/round3-checks/certified-custody.txt`). The audit checks this explicitly
and records which runs carry the flag.

## M5. Tokenizer contract alpha = 1, delta = 0

**Proved and monitored.** `segmentation_count_le`/`tokenizer_alpha_one`: a
tokenization into nonempty pieces whose concatenation equals the input bytes has
at most one token per byte. `ByteBoundedRuntime` checks both premises (native
pieces read with the special-token convention) before every dispatch and refuses
a violation without dispatching. Every certified-study request carries a
segmentation receipt. The `n_ctx_train (0)` message comes from the
vocabulary-only tokenizer load (`vocab_only=True` has no hyper-parameters); it
does not occur for inference contexts.

## Additional finding: Python-to-Lean serialization defect (fixed)

A new Lean encoder and `roundtrip` mode check the serializer exactly. The first
run matched 2,517/3,036 programs: Python's default JSON escaped astral-plane
characters as UTF-16 surrogates, which Lean decoded to U+0000. This affected both
the validator and the static certificate (under-counting a 4-byte character as 2
bytes). No shipped workflow source contains non-ASCII, so no reported result was
affected. Both interfaces now write raw UTF-8; 3,036/3,036 round-trip, a
regression test covers it, and `--ascii-escaped` reproduces the pre-fix failure.
